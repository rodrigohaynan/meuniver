CONVIDATA — PASSO A PASSO PARA PUBLICAR

1) PROJETO SUPABASE
   - Use um projeto Supabase exclusivo da Convidata.
   - Abra SQL Editor e execute supabase/schema.sql.
   - Em seguida execute as migrações da pasta supabase/ em ordem numérica
     (MIGRACAO_002 ... MIGRACAO_019). Onde houver dois arquivos com o mesmo
     número, execute ambos.

2) CHAVES DO SUPABASE
   Project Settings > API:
   - Project URL
   - anon / publishable key
   - service_role key (somente servidor)

3) VARIÁVEIS NO NETLIFY (Project configuration > Environment variables)
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_ANON_KEY
   SUPABASE_SERVICE_ROLE_KEY        (marcar como secreta)
   NEXT_PUBLIC_APP_URL = https://convidata.com.br
   NEXT_PUBLIC_APP_NAME = Convidata
   MERCADO_PAGO_CLIENT_ID           (presentes em PIX)
   MERCADO_PAGO_CLIENT_SECRET       (presentes em PIX, marcar como secreta)
   OPENGRAPH_IO_APP_ID              (opcional: captura de imagens de anúncios)

4) AUTENTICAÇÃO
   Supabase > Authentication > Providers:
   - Email: ATIVADO.
   - Google, Facebook, Phone/SMS, Apple e demais: DESATIVADOS por enquanto.
   Antes de abrir ao público, mantenha a confirmação de e-mail ativa e
   configure um serviço de envio de e-mail (SMTP).

5) URLS DE AUTENTICAÇÃO
   Supabase > Authentication > URL Configuration:
   Site URL = https://convidata.com.br
   Redirect URLs:
   https://convidata.com.br/auth/callback
   https://*--convidata.netlify.app/auth/callback   (deploy previews)
   http://localhost:3000/auth/callback

6) MERCADO PAGO
   Mercado Pago Developers > Suas integrações > aplicação da Convidata:
   Redirect URL = https://convidata.com.br/api/mercadopago/callback

7) NETLIFY
   Repositório: rodrigohaynan/meuniver (branch main).
   Build command: npm run build — o Netlify detecta Next.js. Node 22.

8) TESTE APÓS CADA DEPLOY
   - Criar conta, fazer login e recuperar senha.
   - Criar convite, escolher tema, enviar foto, adicionar presentes, publicar.
   - Abrir /c/slug em janela anônima, confirmar presença, reservar presente.
   - Conferir as respostas no painel.
   - Compartilhar o link no WhatsApp e conferir a prévia.
