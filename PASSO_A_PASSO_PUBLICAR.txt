MEU CONVITE — PASSO A PASSO PARA PUBLICAR (FASE DE TESTES GRATUITA)

1) CRIE UM NOVO PROJETO NO SUPABASE
   - Não use o banco do convite da Liene.
   - Abra SQL Editor.
   - Cole e execute todo o conteúdo de supabase/schema.sql.

2) COPIE AS CHAVES DO SUPABASE
   Project Settings > API:
   - Project URL
   - anon / publishable key

3) CONFIGURE AS VARIÁVEIS NO NETLIFY
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_ANON_KEY
   NEXT_PUBLIC_APP_URL
   NEXT_PUBLIC_APP_NAME

4) AUTENTICAÇÃO GRATUITA PARA O MVP
   Supabase > Authentication > Providers:
   - Email: ATIVADO.
   - Google: DESATIVADO.
   - Facebook: DESATIVADO.
   - Phone/SMS: DESATIVADO.
   - Apple, Azure, Discord e demais provedores externos: DESATIVADOS.

   Para testar sem depender de serviço de e-mail externo, você pode temporariamente
   desativar a exigência de confirmação de e-mail no Supabase. Antes de abrir a
   plataforma ao público, reative a confirmação e configure um serviço de e-mail adequado.

5) URLS DE AUTENTICAÇÃO
   Supabase > Authentication > URL Configuration:
   Site URL = https://SEU-SITE.netlify.app
   Redirect URLs:
   https://SEU-SITE.netlify.app/auth/callback
   http://localhost:3000/auth/callback

6) GITHUB
   Recomendado: criar um NOVO repositório para esta plataforma.
   Não substitua o repositório do convite da Liene enquanto ele estiver em uso.

7) NETLIFY
   Conecte o novo repositório.
   Build command: npm run build
   O Netlify detectará Next.js.
   Node: 22.

8) PRIMEIRO TESTE
   - Criar conta por e-mail e senha.
   - Fazer login.
   - Criar convite.
   - Escolher tema.
   - Enviar foto.
   - Adicionar presentes.
   - Publicar.
   - Abrir /c/slug em janela anônima.
   - Confirmar presença.
   - Reservar um presente.
   - Verificar que o dono enxerga as respostas no painel.

PROVEDORES FUTUROS
   Google, Facebook, telefone/SMS e outros métodos permanecem fora do MVP.
   Eles podem ser habilitados depois, quando houver necessidade real e orçamento.
